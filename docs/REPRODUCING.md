# Reproducing the study

Use Python 3.11 and run commands from the repository root. The package pins the tested NumPy, SciPy, Matplotlib, and PyTorch versions. The README shows installation and the quickest demo/test commands.

## Evaluate the supplied models

```bash
python -m electrolyte_surrogate.demo
python -m electrolyte_surrogate.demo --input data/example_field.csv --output runs/custom-demo
python -m electrolyte_surrogate.evaluate --ablation artifacts/loss_ablation
```

The default demo shows a step, pulse, reversal, and oscillating field over 100 Debye times. It writes `field_responses.png`, four `overview_*_predictions.csv` files, and `overview_metrics.json` to `runs/demo/`. A custom `tau,f` CSV must have uniform spacing 0.05 and zero-field equilibrium prehistory. Plots show the field/bare coefficient and both full interaction-current coefficients.

Evaluation writes to `results/reproduced/`. Omit `--ablation` to skip the six-model loss study. Outputs include standard tests, early-prefix and elapsed-time-regime scores, 32 late-change probes, long-step/switch-off diagnostics, physical weight comparisons, and warmed inference timings. The supplied `results/` were generated by these functions. Signed predictions accompany the tail figures.

## Fit the models

```bash
python -m electrolyte_surrogate.train --model baseline
python -m electrolyte_surrogate.train --model gru
python -m electrolyte_surrogate.train --model physical
python -m electrolyte_surrogate.evaluate --artifacts runs/training
```

Fits go to `runs/training/` as `baseline.npz`, `gru.pt`, and `covariance_weights.npz`. Evaluation requires all three. The GRU also writes `training_history.json`. `--seed`, `--warmup-epochs`, and `--epochs` control its initialization and two training budgets.

The reference GRU uses seed 13, 32 hidden units, batches of 64, scaled MSE, and gradient clipping at 1. A 120-epoch warm-up on the 0–12 prefix uses Adam at 0.003 and a validation plateau scheduler (factor 0.5, patience 7). Twenty continuation epochs use complete 0–100 histories, the retained optimizer/RNG states, and learning rate 0.0003. Output scales stay fixed at training-prefix RMS. Full-history validation selects the checkpoint with a 1e-4 improvement tolerance; the supplied fit selects continuation epoch 20.

Regression fits the same full histories and scales. Validation selects 120 lags and ridge factor 1e-5 from windows 20/60/120 and factors 1e-5/1e-3/1e-1. Features use past f and f³ for the electrostatic term and past f² for the even hydrodynamic coefficient.

Physical fitting retains the selected 24-by-12 grid. It learns nonnegative weights with ridge factor 1e-5 and stationary constraints at 11 training amplitudes, using fine-grid on/off curves through time 1,000. Four amplitudes provide validation and five separate amplitudes form the tail diagnostic. This is a separate supervised reduction problem with known dynamics and longer targets.

## Reproduce the controlled loss study

```bash
python -m electrolyte_surrogate.ablate
python -m electrolyte_surrogate.evaluate --ablation runs/loss-ablation
```

The study uses seeds 13, 29, and 47. Each pair shares its 120-epoch warm-up state and receives 20 complete-history epochs with matched batch order. Only the added stationary-centered late-asinh term differs. Both use the predeclared final epoch, rather than the reference command's validation-selected checkpoint. Training-only calibration, objectives, endpoint selection, and uncertainty conventions are specified in [EXPERIMENT.md](EXPERIMENT.md).

This full experiment was run from a fresh local checkout. The seed-13 MSE endpoint reproduces every supplied GRU parameter bit for bit on the recorded platform. This verifies a complete training trajectory; it does not promise bitwise identity across hardware or library versions. Per-phase training durations and software/source hashes are supplied with the study; hardware and verification details are in [VERIFICATION.json](VERIFICATION.json). The recorded training phases totaled 62.4 minutes on a four-core Intel Core i7 MacBook Air with 8 GB RAM and two PyTorch threads. The full reference-GRU reproduction took 13.8 minutes. These timings describe reproduction cost, rather than a controlled speed comparison between losses. Training is optional.

## Rebuild the synthetic data

```bash
python -m electrolyte_surrogate.generate_data
python -m electrolyte_surrogate.protocols
```

The commands write `dataset.npz` and `timing_probe.npz` to `runs/generated_data/`, with configuration files. Add `--data runs/generated_data/dataset.npz` when fitting, and `--data` plus `--timing-data` when evaluating rebuilt records.

The learning file contains `tau (2001,)`, `field (1088,2001)`, `target (1088,2001,2)`, and `split`/`family` arrays. Whole histories define 768 training, 128 validation, 128 standard tests, and two 32-history challenge sets. Changes occur by time 10; final fields are held through time 100. Labels use quadrature 48/48 and are stored as float32. A direct rebuild can differ slightly from the archived blockwise extension; five complete regenerated labels were checked to numerical tolerance.

The evaluation-only timing file contains 32 new step/pulse/reversal/switching histories generated with seed 20261027. Changes span the full window, amplitudes stay inside the training range, and float64 labels use quadrature 96/64. Refinement against 48/48 is recorded. These probes never enter fitting or model selection.

## Tests and numerical conventions

GitHub Actions installs the package on Linux/Python 3.11, checks supplied hashes, runs the tests, and exercises the custom-field CLI. On Linux, the smaller CPU wheel can be installed before the editable package with `python -m pip install torch==2.2.2 --index-url https://download.pytorch.org/whl/cpu`.

NRMSE divides current RMSE by reference-current RMS. Hydrodynamic scores exclude the known `-f` baseline. Recent/intermediate/long-hold bins use time since the latest field change: below 1, 1–8, and at least 8. Reference RMS of zero gives JSON `null` for NRMSE, while absolute RMSE remains available. Current-level accuracy and relative accuracy of tiny stationary departures answer different questions.

GRU inference is float32; physical calculations are float64. Tail diagnostics subtract the same true stationary value and record numerical floors. The long-step suite follows earlier exploration and is not a blind benchmark. These are finite-window fits to synthetic theory, with no claim of experimental validation or universal neural-memory limitations.
